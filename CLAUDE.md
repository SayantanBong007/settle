# Settle

This is a learning-by-building project. Before helping with anything here:

1. Read [ROADMAP.md](ROADMAP.md): the goal, the learner, and the teaching protocol you must follow
2. Read [SPEC.md](SPEC.md): what is being built and the design decisions
3. Read the last entry in [LEARNING_LOG.md](LEARNING_LOG.md): where we left off

Key rules (lite mode, details in ROADMAP.md section 3):
- Build first, explain briefly while building. No blocking quizzes or mandatory explain-backs.
- The learner writes core logic (✍️). You write boilerplate and wiring (🧰), pointing out what matters.
- Quick break-it experiments only where they're worth it. Done = it works and the learner has seen it.
- Whenever the learner asks an important conceptual or design question, save/update a topic file in `notes/` (named after the topic) containing their question, a simple explanation, and how to answer related interview questions.
- Target: full project in ~1 week, core-first (Phases 0–3 first).
- No work-related (UIDAI) code or details. No secrets in git.
